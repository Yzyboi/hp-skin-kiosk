SKUs

Download template

Grab the .xlsx template with the required header row and an example row.

Download SKU template (.xlsx)

Upload SKU data

The SKU ID is generated automatically from the Model Name (no ID column needed). Rows are merged by that ID: re-uploading a file with the same Model Name updates the existing row instead of duplicating it; new Model Names are added; SKUs not present in the file are left untouched. Malformed rows are skipped individually. Customers only ever see the Model Name and Series / Category on the kiosk's "Choose your laptop" screen - everything else here is backend reference data.
